# Detector de músicas feitas por IA

Ferramenta que acompanha uma playlist do YouTube Music compartilhada entre amigos e avisa num grupo de WhatsApp
quando entra uma música com sinais de ter sido gerada por inteligência artificial.

> 🚧 Em construção — fase de testes das pistas de investigação.

## Pistas avaliadas

| Pista | Situação |
|---|---|
| Aviso "Conteúdo gerado por IA" da Deezer | ✅ funciona |
| Ritmo de lançamentos do artista | ✅ funciona |
| Rastro do artista na web | ✅ funciona |
| Análise do áudio com o modelo SONICS | 🧪 em teste |
| Rótulo de IA do YouTube | ❌ não aparece em músicas de distribuidora |
